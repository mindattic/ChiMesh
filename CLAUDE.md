# ChiMesh Project Rules

## Conversation
- A bare "do" / "do it" / "yes" from the user means "continue", "keep going", "proceed". Resume the current task without asking for clarification.

## Codex — how to work in this repo
ChiMesh follows the MindAttic **Codex** documentation standard. Canon lives in `docs/`:

- `docs/BIBLE.md` (L0) — the single source of truth: what ChiMesh IS, is NOT, and its Laws. Read this first. Sections have stable anchors `{#CM-§N}`; laws are `{#CM-LAW-n}`.
- `docs/AMENDMENTS.md` (L1) — append-only change log (`CM-A1`…). **An amendment wins over the bible.** Never rewrite one; supersede it.
- `docs/USER_STORIES.md` (L2) — stories `CM-US-<Epic><n>`; every `✅` cites its verifying test.
- `docs/rfc/*.md` — design notes; graduate into the bible + stories, then mark superseded.
- `docs/data/` (L5) — canon-as-data. The parts catalog's single home is `config/parts.json`; `docs/data/parts.json` registers it against `docs/data/_schema/part.schema.json`. Cite parts as `part.<id>`; never restate their fields in prose.
- `docs/BIBLE.digest.md` — GENERATED by `tools/codex.ps1 digest`. Never hand-edit.

**Rules of engagement**
- Single home per fact: parts → `config/parts.json`; pinned upstream versions → `config/versions.json`; narrative → `README.md`; rules → `docs/BIBLE.md` / inherited `MindAttic.HouseRules.md`. Link by ID; don't duplicate.
- Org-wide rules are inherited from `../MindAttic.HouseRules.md` (`HOUSE-LAW-1`…). Don't restate or modify them; project-specific laws live in `docs/BIBLE.md` §5.
- Hardware-safety laws are non-negotiable: LiFePO4-only (`CM-LAW-1`), never-USB-while-cell-wired (`CM-LAW-2`), TP5000 LFP jumper (`CM-LAW-3`), SMA-not-RP-SMA (`CM-LAW-4`).
- "Done is verified, not asserted" (`HOUSE-LAW-8`): mark `✅` only when a test/build proves it; otherwise `🟡`/`⬜`.

**Tooling** (Windows PowerShell 5.1 — no `pwsh` on this host):
```
powershell -NoProfile -ExecutionPolicy Bypass -File tools\codex.ps1 digest   # regenerate docs/BIBLE.digest.md
powershell -NoProfile -ExecutionPolicy Bypass -File tools\codex.ps1 doctor   # validate canon; must exit 0
```
`doctor` must pass before any docs change is considered done. A `SessionStart` hook (`.claude/hooks/inject-digest.ps1`) injects the digest as authoritative context at the start of each session.

Render + deploy of the landing page is out of this repo — see `.claude/commands/deploy.md` (sibling MindAttic.Deploy). Do not re-implement rendering or FTP here.
